# Overview
OpenGl이 정의하는 여러 구성 요소에 대해서 다룬다.

# Viewport
렌더링을 수행할 평면. 생성한 윈도우 영역의 일부로 직사각형이다. 뷰포트를 정의하기 위해서는LD(Left Down) 점의 좌표와 너비(Width), 높이(Height)가 필요함. 

viewport는 하나의 좌표계로 기능하는데, 이 것이 최종적으로 rendering 되는 pixel의 위치와 연결된다. viewport 좌표계는 중심은 (0, 0)이고 절댓값이 1 이하인 x, y값으로 구성된다.

# Swap Chain
렌더링의 목표는 결국 이미지를 생성하는 것이다. 이미지는 정수 튜플의 2차원 배열로 생각될 수 있으며, 튜플을 구성하는 각 값이 색을 의미한다. 

 이렇게 gpu가 생성한 이미지는 디스플레이에 제출하여 화면에 출력되는데, 이미지 데이터를 임시로 저장하는 버퍼를 두어 관리한다. 

**스왑 체인은 이미지 버퍼를 여럿 두는 것을 의미한다.** 이미지 버퍼를 여럿 두면 디스플레이와 gpu 사이의 동기화에서 오는 연산력의 낭비를 줄일 수 있다. 

cpu가 수행하는 각각의 렌더링 루프는 cpu가 gpu에게 보내는 각각의 렌더링 명령을 의미한다. gpu는 설정된 상태값과 제공된 렌더링 자원을 바탕으로 렌더링(이미지 생성)을 수행하고, 디스플레이에 해당 이미지의 출력을 명령한다.  이 때, 이미지의 생성과 디스플레이로의 출력이 별도로 수행된다.

따라서, 이미지 버퍼를 두 개 만든 다음, 한 버퍼에는 렌더링을 수행하게 하고, 다른 한 버퍼는 출력의 대상으로 삼는다. 보통 출력의 대상이 되는 버퍼를 front buffer라 하고, 렌더링의 대상이 되는 버퍼를 back buffer라 한다. 그 다음 렌더링 루프에서는 이 두 버퍼를 교체하여 해당 작업을 반복한다. 이런 버퍼의 교체를 swap이라고 하므로, 두 버퍼를 swap chain이라고 부른다.

두 버퍼를 각각 따로 운영하는 것으로 gpu와 display가 서로를 기다리느라(동기화 하느라) 생기는 낭비를 최소화 한다.
