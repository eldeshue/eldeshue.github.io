# Overview
리눅스 커널 코드를 보며 오해했던 메모리 관련 개념에 대해서 정리한다.

특히 물리 주소, 가상 주소, PTE 등이 모두 64bit다 보니, 이들 사이의 의미에 대한 혼동이 있었다. 이에 한 번 정리하고 넘어간다.
# Contents
## 물리 주소
실제 RAM 등 하드웨어에 제공되는 값을 읽기 위한 값.

운영체제가 제공해야 하는 **공평한 서비스**를 위해서 가상 주소로 다루어짐.
## 가상 주소
CPU가 계산하여 생성하는 값. 메모리에 대한 간접적인 표현식.
## PTE
가상 주소와 물리 주소를 매핑하는 테이블, Page Table에서 테이블의 각 entry, 하나의 페이지에 대한 정보를 저장하는 엔트리.

마찬가지로 64비트이며, 엔트리에는 상위 비트들에 대한 변환 뿐 아니라 각 페이지에 대한 메타데이터(접근 권한, 보안 정보 등)를 담고 있다.
