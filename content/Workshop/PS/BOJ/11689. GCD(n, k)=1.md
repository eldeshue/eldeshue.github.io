# Problem

- [link](https://www.acmicpc.net/problem/11689)
# Solution

오일러 피 함수는 어떤 N에 대하여 N과 서로소인 수의 갯수를 구하는 함수이다.

# Implementation

## Code
``` cpp
/*
    BOJ 11689

    오일러 피 함수를 활용하는 문제
    단순 활용인 줄 알았지만....
*/
#include <cmath>
#include <iostream>
#include <numeric>
#include <vector>

using ll = long long;

int main()
{
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    std::cout.tie(nullptr);

    // input
    ll N;
    std::cin >> N;

    const ll origin = N;
    std::vector<ll> prime;
    for (long long i = 2; N > 1; ++i) // worst, O(N) -> TLE
    {
        if ((N % i) == 0)
        {
            prime.push_back(i);
            while ((N % i) == 0)
            {
                N /= i;
            }
        }
    }

    // calculate euler phi
    if (prime.empty())
        std::cout << N - 1;
    else
        std::cout << std::accumulate(prime.begin(), prime.end(), origin, [](const ll acc, const ll p)
                                     { return (acc / p) * (p - 1); });
}
```
위 코드는 TLE를 받고 실패한 풀이다. 먼저 소인수를 모두 구한 다음, 이 소인수에 대해서 오일러 피를 돌려서 답을 구하려고 했다.

그러나 이 풀이의 경우, 소인수를 구하는 과정에서 N이 소수일 때, O(N)을 돌아버리며 TLE를 낸다.

``` cpp
/*
    BOJ 11689

    오일러 피 함수를 활용하는 문제

    O( sqrt(N) ) 복잡도의 실현을 위해서 소수를 구한 다음 빼지 말고,
    미리미리 빼서 나아간다.

    특히 소수는 sqrt(N)이하에 존재하거나 아니면 그 자신이 소수다.
    이 성질을 활용해서 N을 sqrt(N)으로 줄일 수 있다.
*/
#include <iostream>

using ll = long long;

int main()
{
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);

    // input
    ll N;
    std::cin >> N;

    ll result = N; // 오일러 피 함수 결괏값

    // prime decomposition, O( sqrt(N) )
    for (ll i = 2; i * i <= N; ++i)
    {
        // i가 N의 소인수인 경우
        if (N % i == 0)
        {
            // phi(N) = phi(N) * (1 - 1/i)
            // 즉, result = result / i * (i - 1)
            // phi함수를 돌려서 미리 빼준다. 여기가 우아한 부분
            result = (result / i) * (i - 1);

            // 해당 소인수로 더 이상 나누어지지 않을 때까지 나눔
            while (N % i == 0)
            {
                N /= i;
            }
        }
    }

    // 반복문을 빠져나왔는데 N이 1보다 크다면,
    // 그 N 자체가 소수이자 마지막 소인수라는 의미
    //
    if (N > 1)
    {
        result = (result / N) * (N - 1);
    }

    std::cout << result << '\n';

    return 0;
}
```
위 풀이의 경우 미리 오일러 피를 돌려서 답을 제거해 나간다.

가장 핵심 코드는 N이 1보다 큰 경우를 활용하여 N이 소수인 상황을 별도로 수행한다. 이 N이 소수인 경우를 별도로 처리하는 구현을 통해서 최악의 경우를 예방한다.
## About Code

## Time Complexity - O( N^0.5 )
소수가 가능한 범위 내에서만 오일러 피 함수를 수행하고, 마지막 N이 소수인 경우에 대해서만 예외처리를 수행한다.
## Spatial Complexity - O(1)
