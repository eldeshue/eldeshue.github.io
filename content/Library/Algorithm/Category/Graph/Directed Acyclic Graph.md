# Description
그래프의 한 종류로, 방향성을 가지고(Directed) 사이클을 갖지 않는(Acyclic) 그래프를 특별히 DAG라 한다.

여타의 그래프와 특별히 구분되는 이유는, 이 dag가 어떤 존재들 사이에서 의존성을 표현하기에 아주 적합한 구조이기 때문이며, 매우 많은 개념이 DAG의 형태로 모델링 된다.

사실 DAG 자체로는 큰 의미가 없지만, 이 DAG에서 빛을 발하는 알고리즘이 있으니, 바로 위상 정렬이다. 이 위상 정렬을 통해서 그래프를 선형화 할 수 있다.
