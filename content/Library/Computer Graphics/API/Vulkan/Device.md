# Overview
Vulkan api에서 hardware(gpu)를 어떻게 추상화 하는지 알아보자.

Dx12의 DXGIAdapter, D3D12Device, 등에 해당한다.
# VkInstance
Vulkan의 컨텍스트 그 자체를 의미함.

vulkan은 그 특성 상, 시스템에게 현재 사용할 수 있는 기능을 물어보고 협상하는 과정이 필요함. 이 vulkan api에는 extension의 형태로 기능을 추상화 하는데, instance 생성 과정에서 어떤 extension을 사용할 것인지 명시적으로 전달해야 함. 

이는 layer 또한 마찬가지임. 다만 layer는 보통 debugging 용도이기 때문에 큰 관련이 없을 것으로 보임.

협상의 결과, 해당 extension이 존재한다면 dynamic loading하여 해당 기능을 추가한다.

DX12의 DXGI에 상응하는 것으로 보임. 
# VkPhysicalDevice
그래픽 하드웨어의 물리적인 측면을 추상화 한 객체.

현재 시스템이 인식하고 있는 여러 그래픽 하드웨어 중 하나를 의미한다.

쿼리를 통해 현재 시스템에 물려있는 디바이스의 정보를 얻어서 그들 중 선택을 할 수 있다.
그 밖에도 여러 성능 제한, 등 정보를 얻을 수 있음.

DXGIAdapter에 상응한다.
# VkDevice
그래픽 하드웨어의 논리적인 측면을 추상화 한 객체.

앞서 생성한 VkPhysicalDevice에서 생성한다.

하드웨어의 논리적 측면이라 이야기 한 이유는 한 실물 하드웨어를 여러 개 처럼(마치 논리코어) 사용할 수 있기 때문이다. 그렇기에 논리적 디바이스이다.

D2D12Device에 해당한다.

놀랍게도 큐와 관련하여 초기화 할 데이터가 상당히 존재한다. DX12에서는 없는 부분임.
일단 해당 디비이스에서 생성할 큐의 패밀리(종류)를 지정한다.

또한 지정한 큐패밀리에 인덱스를 지정해서 추후에 큐를 생성할 때 이를 사용함.
