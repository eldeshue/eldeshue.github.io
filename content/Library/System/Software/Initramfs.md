# Overview
Initramfs는 Initial Ram File System의 축약어로, 리눅스 부팅 과정에서 일시적으로 발생하는 굉장히 흥미로운 설계이다.
# Contents
## Problem: 부팅 과정의 모순 - 파일 시스템
부팅 과정에서 커널은 파일 시스템을 필요로 한다. 문제는 파일 시스템 초기화에는 부팅이 필요하다는 점이다.

커널 모듈에 대해서 생각해보자. 커널은 부팅을 완료하기 위해 모듈 로딩이 필요하다. 이러한 모듈은 파일로 구성되고, 부팅을 위해선 파일 시스템이 필요하며, 파일 시스템은 부팅이 필요하다는 모순에 빠진다.

> **문제는 디스크도 외부장치다.** 

따라서 커널은 디스크를 인식하는 도구, 즉 드라이버가 필요하다. 드라이버는 파일이므로, 디스크에서 읽어야 한다. 또 다시 모순에 빠지게 된다.
## Solution: Ram mount File System
이러한 모순을 해결하는 것이 바로 Initramfs이다.

파일시스템은 보통 디스크에 마운트 되지만, **ram에도 마운트할 수 있다**. 따라서 ram에 일시적으로 파일 시스템을 설치하는 것이다.

부팅 과정에서 필요한 극히 필수적인 드라이버로 구성된 임시 파일 시스템을 구성하여 cpio 아카이브 형태로 압축한 다음 커널 이미지에 포함하거나 부트로더로 하여금 ram에 적재시킨다.

이후 부팅의 초기 과정에서 이를 ram에 바로 압축해제한 다음, 즉시 마운트하여 사용한다. 

이후 부팅이 완료되면, 파일시스템을 디스크에 마운트한다. 이러한 마운트 위치 변환을 **switch root** 혹은 **pivot root**라고 부른다.
