# Overview
리눅스 커널이 메모리를 어떻게 관리하는지에 대해서 정리한다.
# Contents
## 물리 주소
실제 RAM 등 하드웨어에 제공되어 값을 읽기 위한 주소.

운영체제가 제공해야 하는 **공평한 서비스**를 위해서 가상 주소로 다루어짐.
## 가상 주소
CPU가 계산하여 생성하는 값. 메모리라는 자원에 대한 핸들.
## Page Table
가상 주소라는 핸들을 실제 유의미한 값(물리 주소)로 변환하는 테이블. 가상-물리 주소 사이의 변환(매핑)은 이 page의 단위로 처리된다. Page Table을 구성하는 각 Entry(줄여서 PTE)는 매핑 뿐 아니라 메타데이터를 저장한다.

PTE는 64비트이며, 엔트리에는 상위 비트들에 대한 변환 뿐 아니라 각 페이지에 대한 메타데이터(접근 권한, 보안 정보 등)를 담고 있다.

이 페이지 테이블은 여러 단계로 중첩되어 있으며, 보통 3단계(설정마다 다름)로 구성된다.

각 단계별 변환은 단계별로 일정 영역의 bit가 변환되어 수행된다.
