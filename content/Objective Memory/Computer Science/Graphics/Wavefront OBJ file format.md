# Overview
3D 오브젝트(Mesh)를 정의하는 가장 흔한 형태인 .obj 포맷에 대하여 정리한다.

기본적으로 OBJ 포맷은 단순 메시 뿐 아니라 여러 spline 등 애니메이션을 위한 정보를 저장하지만, 이 글의 목적은 어디까지나 폴리곤 메시와 텍스처 관련 정보를 정의하는 방법에 대한 내용이므로 패스한다.

오랜된 포맷이라 제공하는 기능에 제한이 있지만, 그 심플함은 당면한 목표를 달성하기에는 충분하다.

기본적으로 확장자로는 .obj와 .mod가 존재하며, 여기서는 ascii text로 정의하는 .obj에 대해서 다룬다.
# Description
## Identifier
.obj는 line-by-line으로 구분되며, 각 line은 다음의 identifier로 시작하여 type을 구분한다.

- v : vertex, 정점의 좌표를 표현함. 3개의 float
- vn : vertex normal, 정점의 법선 벡터를 표현함. 3개의 float
- vt : vertex texture, 텍스쳐의 좌표를 표현함. 2개의 float
- f : face, 평면을 표현함.
- g : group, 별도의 geometry group. 그룹의 name이 되는 string
- '#' : 주석 

f는 v, vn, vt의 3종의 인덱스가 모인 튜플로 구성된다. 기본적으로 face는 vertex의 인덱스를 필수적으로 포함하며, 나머지 두 필드의 경우에는 선택적으로 포함될 수 있다. 평면을 구성하는 vertex의 개수만큼 튜플이 필요하며, 적어도 3개의 튜플이 필요하다. 만약 3개보다 많은 vertex로 구성된 face라면, 여러 삼각형(보통 n - 2개)으로 분할할 필요가 있겠다.

``` OBJ
f v0/vn0/vt0 v1/vn1/vt1 ...
```

g는 그룹을 의미하며, 구분된 별도의 물체를 의미한다. 이는 하나의 .obj파일에서 여러 mesh를 얻을 수 있음을 의미하는데, 그 정의가 상당히 애매하다.

``` OBJ
# group example 1
v 0.000000 2.000000 2.000000
v 0.000000 0.000000 2.000000
v 2.000000 0.000000 2.000000
v 2.000000 2.000000 2.000000
v 0.000000 2.000000 0.000000
v 0.000000 0.000000 0.000000
v 2.000000 0.000000 0.000000
v 2.000000 2.000000 0.000000

g front_cube
f 1 2 3 4
g back_cube
f 8 7 6 5
g right_cube
f 4 3 7 8
```
한 경우는 한 곳에 모든 mesh 관련 자원을 정의하고, 이후 각 group을 정의할 때, 이들을 참조하는 방식이다.
``` OBJ
# group example 2

g front_cube
v ...
v ...
v ...
v ...
vn ...
vn ...
vn ...
vn ...

f 1 2 3 4
f ...
f ...

```
OBJ 포맷에서 정의하는 인덱스는 1-based 이며, 음수가 존재할 수 있는데, 음수는 역방향을 의미한다. 즉 1은 가장 먼저 정의된 대상을, -1은 가장 마지막에 정의한 대상을 가리킨다. 당분간 음수 인덱스는 구현하지 않는다.
