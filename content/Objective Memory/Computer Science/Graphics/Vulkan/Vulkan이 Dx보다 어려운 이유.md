# 파편화를 고려한 설계
Vulkan은 시스템의 환경이 어떻게 될지 모른다는 문제가 있음.

따라서 여러 기능을 사용할 때, Dx처럼 확신을 가질 수가 없음.

따라서, 항상 모종의 쿼리를 통해서 물어보고 그 기능을 사용하게 됨.

# COM의 부재
놀랍게도, COM은 유용한 feature였음.

COM이 있기 때문에 상속에 기반한 여러 도움을 얻을 수 있었던 것으로 생각됨.

그 외의 영역을 둘 모두 어느 정도 handle의 형태로 추상화 되기에 비슷한 경향이 있음.
