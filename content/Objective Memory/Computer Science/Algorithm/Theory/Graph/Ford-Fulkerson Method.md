# Prerequisite Algorithm
# Description

## 최대 유량이란?

어떤 그래프에 대하여, 간선에 용량(capacity)이 주어진 경우를 유량 네트워크(flow network)라 한다. 최대 유량은 어떤 유량 네트워크에 대하여 임의의 출발 점(source)과 끝 점(sink)을 주었을 때, source에서 sink를 향하여 각 간선의 용량을 어기지 않으면서 흘릴 수 있는 가장 큰 유량을 뜻한다.

이러한 복잡한 최대 유량 문제를 구하기 위해서 잔여 네트워크(residual network)라는 개념을 도입한다.
## 잔여네트워크

잔여네트워크란 기존의 유량 네트워크를 구성하는 각 edge에 대하여 방향은 반대이며, 용량은 0, 음의 flow를 허용하는 간선, 일명 역방향 간선(backward edge)를 추가한 것이다. 

residual network를 순회하는 과정에서 역방향 간선을 거치는 것은, 이전에 흘렸던 유량을 취소하여 새로운 방향으로 흘림을 의미한다.

즉, **잔여 네트워크란 유량의 취소를 구현할 수 있는 네트워크**다.

## 증가 경로

증가 경로(augment path)는 잔여네트워크 상에서 존재하는 경로로, 문자 그대로 네트워크의 유량을 증가시키는 경로이다. 

이 증가 경로를 구하기 위해서 잔여네트워크를 도입하였다. 증가 경로가 발견될 수 있는 이유는 잔여 네트워크의 순회 과정에서 기존의 유량을 취소할 수 있기 때문이다.
## Ford-Fulkerson method
포드-펄커슨 방법이란 잔여 네트워크를 활용하여 최대 유량을 구하는 방법을 의미한다. 이 것이 알고리즘이 아닌 방법인 이유는 그 구현의 상세가 존재하지 않기 때문이며, 이 방법을 구현한 여러 알고리즘이 존재한다.

포드-펄커슨 방법을 간단하게 요약하면 잔여네트워크를 순회하여 유량이 더 늘어나지 않을 때 까지 증가 경로를 탐색하고, 탐색한 증가 경로로 유량을 증가시키는 것이다. 그러나 이 증가 경로를 어떻게 구할 지에 대한 방법이 제시되지 않았다.

## 최소컷 최대유량 정리

정리는 다음과 같다. 

```
한 유량 네트워크의 최대 유량은 곧 해당 네트워크에서 얻을 수 있는 최소 컷과 같다. 
``` 

한 잔여네트워크 상에서 증가 경로를 발견할 수 없음은, 곧 유량네트워크에서 더 이상 흘릴 수 있는 유량이 없음을 의미한다. 

이는 잔여네트워크 상에서 source와 sink가 분리되었음을 의미한다. 즉 source가 속하는 그래프와 sink가 속하는 그래프가 서로 다르다. 이는 그래프의 분리를 의미하며, 컷(cut)을 구성한다.

동시에 잔여네트워크 상에서 더 이상 증가 경로를 발견할 수 없음은 곧 유량 네트워크에서 최대 유량을 의미한다.

직관적으로 생각하면, 어느 flow path의 유량은 곧 해당 경로를 구성하는 간선 중에서 병목이 되는 간선이 결정한다. 그러므로, 어느 유량 네트워크의 최대 유량은 곧 각 path의 병목이 되는 capacity의 총 합이 되며, 이는 곧 최소 컷의 유량이 된다.
